PROBLEMA DE VALOR INICIAL

Configura la ecuación

Ingresa la ecuación despejada como y′ = f(x,y), el dato inicial y el punto final. Para esta guía: (y²−x²)dx + xy dy = 0, con y(1)=2.

¿QUÉ CALCULA?

Dos aproximaciones

Euler explícitoUsa la pendiente al inicio del paso: yₙ₊₁ = yₙ + h f(xₙ,yₙ).
Euler mejorado · HeunCalcula una predicción, evalúa la pendiente final y promedia las dos pendientes.
ComparaciónCuando ingresas y(x), calcula error absoluto y error relativo porcentual.
